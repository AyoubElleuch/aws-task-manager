# Security Policy

## Supported versions

Security fixes target the latest code on `main`. Older revisions and development branches do not receive separate security updates.

## Reporting a vulnerability

Report vulnerabilities privately through the repository's [Security Advisories](https://github.com/AyoubElleuch/aws-task-manager/security/advisories) page using **Report a vulnerability**.

If that option is unavailable, [open an issue](https://github.com/AyoubElleuch/aws-task-manager/issues/new) requesting a private security contact. Include only the contact request, without vulnerability details or proof-of-concept code.

In your private report, include:

- The affected component and commit or version.
- A description of the vulnerability and its potential impact.
- Steps to reproduce it or a minimal proof of concept.
- Relevant logs or screenshots, with credentials, tokens, and personal data removed.

## Coordinated disclosure

Please allow time to verify the report and prepare a fix before publishing vulnerability details. Any disclosure timeline can be agreed upon during the private discussion.
